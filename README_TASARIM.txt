EBS Word Studio - Tam Ekran Responsive Arayüz

Yapılanlar:
- Büyük logo, dekoratif resim ve kartlar kaldırıldı.
- Android durum çubuğu gizlenerek tam ekran düzen sağlandı.
- Açılan Word/DOCX belgesinin metni kullanılabilir ekran yüksekliğini doldurur.
- Ekran daraldığında üst eylem araç çubuğu yatay kaydırılabilir.
- Aç, Kaydet, Farklı Kaydet, Yeni, Kopyala, yazı boyutu ve sayaç işlevleri korundu.
- Var olan DOCX metin okuma/yazma altyapısına müdahale edilmedi.

Önemli: Orijinal projedeki DocumentCodec eski ikili .doc formatını desteklemez.
DOCX desteği metin tabanlıdır, Word sayfa biçimlerini aynen göstermez.

Kaynak proje: Android Studio'ya içe aktarılarak derlenebilir.
Bu pakette derlenmiş APK bulunmaz; burada Android SDK bulunmadığından derleme test edilmedi.
